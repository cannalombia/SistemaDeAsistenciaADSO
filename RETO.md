# Reto aplicado: planeacion de BioSecure SENA 9.1

La practica del portafolio se adapta al producto real. La entrega exige seis historias INVEST, defectos reproducibles, tablero publico, trazabilidad y pruebas honestas.

No se considera terminado el reto por el numero de tarjetas. La evaluacion debe comprobar que:

- las plantillas aparecen en `Issues > New issue` desde `main`;
- las seis HU y los bugs usan numeros reales, etiquetas y responsable;
- solo trabajo verificado queda en `Done`;
- ningun issue, commit o evidencia publica contiene datos personales, claves o biometria;
- `node verificar-plan.js` aprueba la estructura y consulta GitHub cuando hay autenticacion;
- la asistencia fisica MySQL y la persistencia de permisos tras reinicio se mantienen pendientes hasta ser demostradas.
