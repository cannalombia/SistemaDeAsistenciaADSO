ARCHIVOS PRINCIPALES

- ABRIR_PROYECTO.cmd
  Opcion recomendada en Windows. Inicia el servidor y abre el navegador.

- index.html
  Punto de entrada visible en la carpeta raiz. Abre la pantalla de acceso.

- aplicacion/paginas/login.html
  Pantalla de acceso. En el navegador conserva la direccion /login.html.

- servidor/servidor.js
  Servidor Node.js, autenticacion, permisos y rutas de la API.

- servidor/modulos/correo.js
  Cola, reintentos, proveedores y plantilla del codigo de acceso.

- aplicacion/recursos/scripts/navegacion.js
  Unica fuente del menu lateral para administrador y aprendiz.

- datos/importaciones/usuarios_activos.csv
  Fuente activa de usuarios. Su nombre permanece estable porque el sistema la actualiza.

- herramientas/automatizacion/asegurar_servidor.ps1
  Comprueba el servidor y lo inicia cuando sea necesario.

- herramientas/automatizacion/vigilante_servidor.ps1
  Mantiene la aplicacion disponible en segundo plano.

- pruebas/prueba_proyecto.js
  Recorridos de integracion de paginas, permisos y API.

- pruebas/prueba_modulos.js
  Pruebas rapidas de reglas, CSV y utilidades.

COMANDOS DE TRABAJO

- Iniciar:                   npm.cmd start
- Comprobar estado:          npm.cmd run status
- Instalar inicio automatico: npm.cmd run install:autostart
- Ejecutar pruebas:          npm.cmd test
- Solo pruebas unitarias:    npm.cmd run test:unit
- Solo integracion:          npm.cmd run test:integration
- Restablecer administrador: npm.cmd run reset:admin

CRITERIO DE FECHAS

Los documentos, horarios, archivos originales y respaldos llevan la fecha
YYYY-MM-DD. Los archivos activos de codigo y datos conservan nombres estables
para no romper enlaces, comandos ni automatizaciones.

DUPLICADOS Y TEMPORALES

No se elimino ningun archivo. El archivo
datos/importaciones/2026-08-07_usuarios_originales.xlsx se conservo como fuente
original y los disenos anteriores permanecen en respaldos/2026/08/diseno.
Los archivos temporales y registros *.log se mantienen fuera de Git mediante
.gitignore.

Los datos operativos, documentos originales y respaldos siguen en este
computador, pero no se publican en Git. Una copia nueva comienza con los datos
anonimos guardados en datos/ejemplos.

SEGURIDAD

Este indice no contiene usuarios, contrasenas ni claves de correo. La clave del
administrador se restablece desde la terminal con npm.cmd run reset:admin.
