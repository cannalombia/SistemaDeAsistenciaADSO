Sistema de Asistencia SENA

El código fuente, las pruebas y la documentación están publicados correctamente en GitHub.

La aplicación completa no puede ejecutarse dentro de GitHub Pages.

Usuarios, importación SQL, gráficas, autenticación y reportes dependen del servidor Node.js y de MySQL. GitHub Pages solo entrega archivos estáticos y no puede guardar esa base de datos.

Para probar el sistema localmente, configura las variables indicadas en el README, ejecuta npm start y abre http://localhost:3000/login.html. Para un enlace público permanente se debe desplegar Node.js y MySQL en un hosting compatible.
